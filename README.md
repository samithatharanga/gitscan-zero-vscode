## ✨ Features

- ⚡ **Zero-Latency In-Memory Diagnostics:** Catches secrets as you type before save or git commit.
- 🔒 **100% Air-Gapped Privacy:** Zero network calls, zero tracking. All scans run strictly in local RAM.
- 🛠️ **One-Click Quick Fixes:** `Ctrl + .` (or `Cmd + .`) to instantly mask keys or swap to `process.env`.
- 🎯 **Deep Coverage:** AWS keys, OpenAI/Anthropic tokens, GitHub PATs, Stripe keys, and Private RSA blocks.
